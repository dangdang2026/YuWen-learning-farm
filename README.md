# 一年级语文复习小农场 🌻

> 专为7岁儿童设计的趣味语文复习应用

## 这是什么

一款基于人教版一年级语文教材的互动学习网页，通过农场游戏化机制让小朋友在种植、钓鱼的乐趣中掌握语文知识。

## 核心功能

### 📚 6大知识模块
| 模块 | 内容 |
|------|------|
| 🔤 汉字乐园 | 形近字、同音字、易错笔顺 |
| 🌸 词语花园 | ABB式、AABB式、ABAB式词语 |
| 📜 古诗背诵 | 赠汪伦、春晓、寻隐者不遇 |
| ✍️ 句子魔方 | 姓氏句式、仿写句子、拟人句 |
| 📖 课文背诵 | 春夏秋冬、姓氏歌、课文主题 |
| 🔡 语文小百科 | 26个字母、音序查字典 |

### 🎮 游戏机制
- **答题奖励** - 答对题目获得金币
- **植物解锁** - 完成模块解锁新植物
- **钓鱼收集** - 每答对3题获得钓鱼机会
- **成就徽章** - 完成学习获得荣誉徽章

### ✍️ 答题方式
| 题型 | 答题方式 |
|------|----------|
| 选择题 | 点击选项 |
| 判断题 | 点击对或错 |
| 填空题 | 打字或语音输入 |

### 🎤 语音输入
支持语音答题，对着屏幕说话即可回答填空题，方便还不会打字的小朋友使用。

## 边界是什么

- ✅ 纯前端，无需后端，数据存储在浏览器本地
- ✅ 无需登录，打开即用
- ✅ 支持桌面端和移动端浏览器
- ❌ 不支持多人协作或数据同步
- ❌ 不提供课程视频或互动教学

## 技术栈

React + TypeScript + Vite + Tailwind CSS + Zustand + Framer Motion
