# 一年级语文复习小农场 - 产品需求文档

> **文档版本**：v3.0  
> **更新日期**：2026-05-11  
> **适用年级**：人教版一年级下册  
> **目标用户**：7岁儿童

---

## 1. 产品概述

一款专为7岁一年级小学生设计的语文复习网页，以「开心农场」为视觉主题，将知识点学习与问答游戏融合，通过思维导图系统展示知识结构，配合可爱的农场养成和钓鱼收集游戏，让孩子在轻松愉快的氛围中掌握一年级下册语文重点知识。

### 核心价值
- **趣味学习**：农场种植+钓鱼收集的双重激励机制
- **系统复习**：交互式思维导图呈现知识结构
- **语音交互**：支持语音输入答题，方便儿童使用
- **整句表达**：填空题采用整句回答，培养完整表达能力
- **亲子友好**：简洁操作，适合孩子独立使用

## 2. 核心功能

### 2.1 页面结构

| 页面 | 路由 | 功能描述 |
|------|------|----------|
| 首页 | `/` | 欢迎界面、开始学习入口、学习进度总览 |
| 知识导图 | `/mindmap` | 可交互的思维导图，展示6大知识模块 |
| 学习练习 | `/learn/:moduleId` | 各知识点的详细学习和配套练习题 |
| 我的农场 | `/farm` | 农场养成界面，展示解锁的植物 |
| 钓鱼池塘 | `/fishing` | 钓鱼收集游戏 |
| 成就展示 | `/collection` | 收集的动植物展示、获得的奖励徽章 |

### 2.2 答题系统

#### 题型类型

| 题型 | 描述 | 语音支持 |
|------|------|----------|
| 选择题 | 4个选项，选出正确答案 | ❌ |
| 判断题 | 对/错二选一 | ❌ |
| 填空题 | 整句填空，支持语音输入 | ✅ |

#### 填空题设计原则
- **整句填空**：用户提供完整句子答案，而非单个字词
- **语音输入**：支持语音识别，儿童可以说出答案
- **模糊匹配**：使用Levenshtein距离算法，允许轻微偏差
- **示例**：
  - 古诗填空："春眠不觉晓，___？" → 答"处处闻啼鸟"
  - 同音字："我___学校学习。" → 答"我在学校学习"

### 2.3 激励机制

```
答对题目 → 获得金币 → 解锁植物 → 装扮农场
    ↓
获得钓鱼机会（每答对3题）
    ↓
钓鱼（90%成功率）→ 收集鱼类 → 鱼类图鉴
    ↓
完成模块 → 获得徽章 → 成就展示
```

### 3.2 模块详细内容

#### 🔤 汉字乐园
- **形近字辨析**：清/请/晴/睛、入/人、王/土、认/队/听/所
- **同音字辨析**：在/再、有/友/右、长/常、明/名、香/乡、时/石
- **易错笔顺**：火（点→短撇→长撇→捺）、为（4笔）、北、走

#### 🌸 词语花园
- **ABB式**：静悄悄、胖乎乎、绿油油、亮晶晶、气冲冲、金灿灿
- **AABB式**：平平安安、蹦蹦跳跳、安安静静、干干净净、认认真真
- **ABAB式**：雪白雪白、碧绿碧绿、金黄金黄、火红火红
- **又×又×式**：又大又圆、又香又甜、又高又壮
- **×来×去式**：飞来飞去、跑来跑去、游来游去

#### 📜 古诗背诵
- **赠汪伦**（唐·李白）：桃花潭水深千尺，不及汪伦送我情
- **春晓**（唐·孟浩然）：春眠不觉晓，处处闻啼鸟
- **寻隐者不遇**（唐·贾岛）：只在此山中，云深不知处

#### ✍️ 句子魔方
- **姓氏句式**：你姓什么？我姓李。什么李？木子李。
- **在...句式**：小鸟在树枝上唱歌
- **...也...句式**：树很孤单，喜鹊也很孤单
- **一...就...句式**：我一听到铃声就进教室
- **拟人句**：星星在夜空中快活地眨眼睛
- **仿写句子**：按照例句结构写类似句子

#### 📖 课文背诵
- **春夏秋冬**：春风、夏雨，秋霜、冬雪
- **姓氏歌**：中国姓氏、单姓与复姓
- **课文主题**：静夜思、端午粽、吃水不忘挖井人、树和喜鹊

#### 🔡 语文小百科
- **26个字母**：A-Z 大小写
- **音序查字典**：口诀与查字步骤

## 5. 问答游戏设计

### 5.1 填空题设计

#### 设计原则
- **整句填空**：用户输入完整句子，而非单个字词
- **一处填空**：每题只留一处空白，降低难度
- **语音支持**：支持语音输入，儿童可以说话回答

#### 示例题目

**古诗填空**
```
题目：古诗填空：
请把后半句补充完整：
春眠不觉晓，___？

正确答案：处处闻啼鸟
备选答案：处处闻啼鸟、处处闻啼、闻啼鸟
```

**同音字填空**
```
题目：请填空（用"在"或"再"）：
"我___学校学习。"

正确答案：我在学校学习
```

**句式填空**
```
题目：请填空（用"一...就..."的结构）：
"___听到铃声，___进教室。"

正确答案：一听到铃声就进教室
```

### 5.2 仿写句子设计

#### 设计原则
- **仅提供结构词**：不给出例句的具体内容，只提供句式结构
- **孩子独立完成**：让孩子根据结构自己写完整句子
- **示例**：
  ```
  题目：仿写句子：
  例句：小鸟在树枝上唱歌。
  请用"在...上..."的结构写一个句子。
  
  正确答案：小鱼在水里游泳
  ```
