
## 7. 核心逻辑

### 7.1 完成度计算

```typescript
const completionRate = Math.round(
  ((unlockedPlants.length + collectedFish.length + earnedBadges.length) / 
  (plants.length + fishes.length + badges.length)) * 100
);
// = (植物 + 鱼类 + 徽章) / (8 + 21 + 6) × 100%
```

### 7.2 答题奖励

```typescript
// 答对题目
updateStreak(true);  // 连续次数+1
addScore(10);        // +10金币

// 每答对3题
if (currentStreak % 3 === 0) {
  addFishingChance(); // +1钓鱼机会
}

// 完成模块
completeModule(moduleId); // 解锁植物+徽章+50金币
```

### 7.3 填空题答案匹配

```typescript
// 使用 Levenshtein 距离进行模糊匹配
const levenshteinDistance = (str1: string, str2: string): number => {
  // 计算两个字符串之间的距离
};

const isAnswerCorrect = (userAnswer: string, correctAnswer: string): boolean => {
  // 精确匹配或模糊匹配
  return userAnswer === correctAnswer || 
         levenshteinDistance(userAnswer, correctAnswer) <= 2;
};
```

### 7.4 钓鱼逻辑

```typescript
// 甩竿
useFishingChance(); // 消耗1次机会

// 判断是否上钩（90%概率）
const success = Math.random() < 0.9;
if (success) {
  setFishingState('bite'); // 鱼上钩
  // 3秒内点击handleCatch()抓鱼
} else {
  setFishingState('waiting'); // 继续等待
}

// 超时处理
setTimeout(() => {
  if (fishingState === 'bite') {
    setFishingState('idle');
    setShowMessage('下次继续努力！');
  }
}, 3000);
```
